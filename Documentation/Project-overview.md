1. Description
The Afghan Antiques Store Management System is a web-based application that helps in managing the operations of a small business selling Afghan traditional and antique items. Items include artifacts, decorative items, handicrafts, and antiques representing Afghan tradition and cultural heritage. 
This project will be developed by a team of four members consisting of a Scrum master, a product owner, and two developers following the Scrum framework and software engineering principles. 
2. Objective
The primary objective of this project is to develop a small, simple, user-friendly application to help manage an Afghan Antique store. 
Main objectives are:
1. Manage products: Only authorized users can add, remove, and update product records.
2. Track stock: Update item numbers when new stock is added or sold.
3. Organize Store Information: Store products, sales, and records of the store in the database.
4. Apply Software Engineering Principles and the Scrum Framework: Use software testing, design, and documentation. Proceed as a team with specific roles, sprint planning, Scrum meetings, sprint reviews, and retrospectives.
