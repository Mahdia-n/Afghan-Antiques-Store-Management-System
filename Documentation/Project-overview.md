## 1. Project Description

The Afghan Antiques Store Management System is a web-based application designed to help customers explore and order traditional Afghan antique products online.

The store includes traditional Afghan items such as handicrafts, decorative products, and antiques that represent Afghan culture and heritage.

Customers can create accounts, browse products, search for antiques, save favorite items, manage shopping carts, and place orders.

Store administrators can manage products, customer information, orders, and sales records.

The main purpose of this project is to create a simple and user-friendly online store for Afghan antique products.

---

## 2. Project Objectives

The main objectives of this project are:

1. Create a simple and easy-to-use online store.
2. Allow customers to register and log in securely.
3. Display Afghan antique products with images, descriptions, and prices.
4. Allow customers to search for products and save favorite items.
5. Provide shopping cart and order submission features.
6. Allow administrators to manage products, customers, and orders.
7. Store and manage information using a MySQL database.
8. Apply Software Engineering principles and Agile Scrum practices.

---

## 3. Main System Features

### Customer Features

- Create an account
- Log in and log out
- Browse Afghan antique products
- View product details and prices
- Search for products
- Save favorite products to a wishlist
- Add products to a shopping cart
- Update or remove shopping cart items
- Provide a delivery address
- Submit orders
- View order history

### Administrator Features

- Update product information
- Remove unavailable products
- Update order progress
- View customer information
- View sales summaries

Some additional features, such as payment status management, product returns, and special offers, are not included in the completed version of the system.

Detailed feature requirements and completion statuses are available in the Product Backlog.

## 6. Development Methodology

The project follows the Agile Scrum methodology.

Scrum helps the team divide project work into short periods called sprints. During each sprint, the team works on selected user stories from the Product Backlog.

The project uses three sprints and includes the following Scrum activities:

- Sprint Planning
- Progress Meetings
- Sprint Reviews
- Sprint Retrospectives
- Product Backlog Refinement

The Product Owner keeps the Product Backlog updated during the project.

The Scrum Master helps organize meetings and supports the team.

The developers build and test the system features.
