## 4. Sprint 3 Retrospective

The team discussed its overall performance during the final sprint and identified lessons learned throughout the development process.

### What Went Well?

- The team successfully completed the two selected Sprint 3 user stories.
- Frontend and backend developers coordinated to implement and integrate the required functionality.
- The Scrum Master facilitated meetings and monitored the team's progress.
- The Product Owner reviewed the completed features and provided feedback.
- The team completed final testing and prepared the project documentation.
- GitHub was used to organize and share project code and supporting documents.

### What Could Be Improved?

- Frontend and backend code should be shared earlier to avoid integration delays.
- Developers should provide more frequent progress updates.
- Testing should be performed continuously rather than postponed until the final sprint.
- Sprint tasks should be estimated more carefully according to the available time.


### Lessons Learned

- Regular communication is important for successful teamwork.
- Staying respectful with the team members and focusing on the team success should be prioritized.
- Early frontend and backend integration reduces development delays.
- Continuous testing helps identify problems earlier.
- Clear task assignments improve accountability.
- Maintaining updated documentation and GitHub contributions provides useful evidence of project progress.
- Product Owner feedback helps ensure that completed features meet the project requirements.
