# Afghan Antique Store Management System – Visual UI Prototype.

The prototype includes nine screens:
1. Home Page
2. Login / Registration
3. Product Catalog
4. Product Details
5. Shopping Cart
6. Checkout
7. Order Confirmation
8. My Wishlist
9. Admin Dashboard / Product Management
